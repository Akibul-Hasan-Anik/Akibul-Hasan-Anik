## Featured Projects

### ClimaCare: Explainable IoT–ML Framework for Microclimate Forecasting

An IoT and machine learning based weather monitoring and forecasting system using ESP32, sensors, FastAPI, React, and Explainable AI.

**Key Features:**

* Real-time sensor data monitoring
* Rainfall, temperature, and humidity prediction
* SHAP-based explanation
* IoT hardware and full-stack dashboard integration

---

### Speech Emotion Recognition

A speech emotion recognition web application that classifies human emotions from audio using a CNN-LSTM deep learning model.

**Key Features:**

* Audio upload system
* Log-Mel spectrogram feature extraction
* CNN-LSTM based emotion classification
* FastAPI backend and web frontend

---

### Explainable Federated ECG Arrhythmia Classification

A healthcare AI project for ECG arrhythmia classification using federated learning and Explainable AI.

**Key Features:**

* ECG signal classification
* Federated Averaging model
* Saliency and Integrated Gradients explanations
* React-based ECG visualization dashboard

---

### Restaurant Food Delivery Web Application

A full-stack restaurant food delivery system with user, admin, and deliveryman panels.

**Key Features:**

* User registration and login
* Food ordering and cart system
* Admin dashboard
* Deliveryman order management
* FastAPI backend and React frontend
